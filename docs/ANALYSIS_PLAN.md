## 二、核心硬性执行原则（不可更改）

1. **处理规则**：
   - GSE31022：**单独处理，不合并任何数据集**
   - GSE63786：**暂不处理**
   - GSE42639：**平台不同，严禁合并，单独分析**

2. **急性期纳入标准**：
   - GSE31022中所有H1N1感染后D1-D6样本**全部纳入**
   - 不筛选具体感染天数、不区分感染剂量
   - 统一归为「流感急性期感染组」

3. **分组统一**：
   - 所有数据集仅设**对照组（Control）**和**感染组（H1N1）**
   - 不拆分时间/剂量亚组

4. **分析阈值**（全流程统一）：
   - `adj.P.Val < 0.05` 且 `|log2FC| ≥ 1`

5. **组织隔离原则**：
   - 全肺数据仅筛选流感相关基因
   - PNECs数据仅筛选咳嗽相关基因
   - 绝不跨组织混合筛选

## 四、详细分析步骤

### 模块1：小鼠流感全肺数据预处理与差异分析

---

#### 步骤1.1 — GSE31022 单独处理（核心步骤）

**数据来源**: `processed_data/GSE31022/GSE31022_non-normalized.txt`
**平台**: Affymetrix Mouse Genome 430 2.0 Array

**样本分组**（新方案）：

| 样本前缀 | 分组 | 说明 |
|---------|------|------|
| Ctrl1, Ctrl2, Ctrl3 | Control | 正常对照 |
| D1-1~3, D2-1~3, D3-1~3, D4-1~3, D5-1~3, D6-1~3 | **H1N1** | 流感急性期感染组（全纳入，不区分天数） |

**预处理流程**:
1. 读取raw数据，提取信号值矩阵
2. 背景校正: `backgroundCorrect()` (normexp方法)
3. 标准化: **quantile normalization**
4. 过滤低表达基因: 检测率 < 50%
5. 过滤异常样本: 样本间相关性 r < 0.8

**差异分析**:
- 分组: **H1N1 (D1-D6全部)** vs Control
- 工具: `limma`
- 阈值: `adj.P.Val < 0.05` 且 `|log2FC| ≥ 1`
- 输出: **基因集A** (小鼠流感急性期差异基因) ✅ **4087个DEGs**

---

#### 步骤1.2 — GSE42639 单独处理（已跳过）

**⚠️ 已跳过**：由于以下问题，决定不纳入此数据集进行交集筛选：
1. Mild H1N1样本 (GSM5398599013-9018) 在原始数据中缺失
2. 即使做Severe vs Control比较，统计效力不足（adj.P.Val > 0.4）

**替代方案**：跳过此数据集，仅用GSE31022基因集A继续后续分析

---

#### 步骤1.3 — 小鼠流感候选基因筛选（简化）

由于GSE42639无法贡献有效基因集，**基因集C = 基因集A**
- 即：轻症流感急性期候选基因集 = GSE31022的急性期差异基因集

### 模块2：小鼠咳嗽相关单细胞数据处理

---

#### 步骤2.1 — GSE304603 小鼠PNECs单细胞分析

**数据来源**: `processed_data/GSE304603/GSM9153868-71_*.h5`
**平台**: 10x Genomics scRNA-seq

**分析流程**:
1. 数据读取: `Read10X_h5()` → `CreateSeuratObject()`
2. 质量控制:
   - 剔除线粒体基因占比 > 10% 的细胞
   - 剔除 UMI数 < 200 的细胞
3. 标准化: `NormalizeData()` (LogNormalize)
4. 降维聚类: `FindVariableFeatures()` → `ScaleData()` → `RunPCA()` → `FindNeighbors()` → `FindClusters()`
5. PNECs细胞群鉴定: 基于标志物基因 **Foxj1**, **Scg2**
6. 差异分析: `FindMarkers()` — 炎症咳嗽PNECs vs 正常PNECs
   - 阈值: `adj.P.Val < 0.05` 且 `|log2FC| ≥ 1`
   - 输出: **基因集D** (小鼠咳嗽高敏相关差异基因)
